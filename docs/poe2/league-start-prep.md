# League Start Prep & Learning a Build

Understanding the build, will also allow you to "stray from the path", should a
Unique drop which could potentially improve the guide your are following (if
you are following a guide).

1. Select a class and ascendancy - Decide when to ascend.
2. Skills
   - Gem cut order + swaps
   - Understand how the skills synergize.
   - Rotation for single target + clear.
   - Optimal hotkey setup.
3. Gear / Items
   - Priority stats (offensive, defensive) to aim for.
   - Other stats to aim for.
   - Item base upgrade breakpoints - especially weapon.
   - Defense type and scaling - AR/EV/ES/Hybrid?
   - **Test item in PoB - Path of Building**. _Remember: YOu can copy the item
     text to PoB to create the item and test it._
4. Pasive Tree
   - Is/can weapon sets be utilized? - set I + II
   - What are we scaling and why/how?
   - Notable priority pathing.
   - Keystones and why they work

> If you're willing to learn how the build "ticks", taking the time to learn
> why it works and repeating this for other good league start guides, will
> serve as a foundation of knowledge which translates into making your own
> builds.
